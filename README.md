# Lost Town Voice

واجهة عربية داكنة بالأسود والذهبي لمشروع تواصل Roblox Roleplay.

## ما الموجود في هذه النسخة؟
- صفحة هبوط عربية متجاوبة.
- عرض توضيحي لميزات الصوت القريب والهاتف واللاسلكي.
- خطوات تركيب وتوضيح صريح أن الموقع لا ينقل الصوت.

## ما الذي لا تفعله هذه النسخة؟
- لا يوجد فيها تسجيل دخول أو قاعدة بيانات أو أكواد تفعيل.
- لا تنقل الصوت بين لاعبي Roblox.
- أزرار الهاتف واللاسلكي المعروضة تعريفية وليست أدوات عاملة داخل اللعبة.

## معاينة محلية
افتح `index.html` مباشرة في المتصفح. يحتاج الخط إلى اتصال إنترنت لتحميل خط Google Fonts، وسيعمل الموقع بخط بديل عند عدم توفره.

## نشر مجاني باستخدام GitHub وCloudflare Pages
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع `index.html` و`styles.css` و`script.js`.
3. افتح Cloudflare Pages واختر إنشاء مشروع وربطه بمستودع GitHub.
4. لموقع HTML ثابت، استخدم إعدادات البناء المناسبة للموقع الثابت؛ عادةً لا تحتاج أمر بناء، واجعل مجلد الإخراج هو جذر المستودع.
5. انشر الموقع واختبره على الهاتف والكمبيوتر.

## ربط Roblox
- استخدم إعدادات Roblox الرسمية لتفعيل الصوت للاعبين المؤهلين.
- `roblox/README.md` يشرح الحدود المعمارية.
- لا تضع مفاتيح API أو أسرارًا في LocalScripts أو ملفات الواجهة العامة.
- `HttpService` مخصص لطلبات HTTP إلى خدمة خلفية؛ لا ينقل الصوت بذاته.

## الترخيص
يمكنك تعديل واجهة هذا المشروع واستخدامها لمجتمعك. هذا المشروع غير تابع رسميًا إلى Roblox أو VoiceBlox.
